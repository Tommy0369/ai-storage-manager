## 5. P4.0 で何をしたか（製品化）

### 凍結
- `FoundationResearchFreeze`  
- 別ブラウザ／別 IDE／大きなフォルダがあるだけでは研究再開しない  
- 再開条件は「新しい archetype / 新しい action / Safety 破綻 / 新しい伝播モデル / 新しい mutation 原始」のみ

### 製品ループ
1. **SEE** — 容量・マップ・変化・回収実績  
2. **UNDERSTAND** — 人間語の What / Why large  
3. **DECIDE** — Keep / Needs verification / Can recover（SafetyClass を前面に出さない）  
4. **ACT** — Fresh Preflight → Approval → Permit → Executor  
5. **VERIFY** — 論理結果・verified bytes・Trash pending の区別  

### UI
- ナビを **Storage / Plan / History / Settings** に整理  
- Technical/Debug は Settings 配下  
- Sunburst + Structure/Meaning/Decision レンズ  
- Cursor / Voice Memos / Chrome / Claude の人間向けタイトル強化  
- 選択の非同期取り違え防止（`PresentationSelectionBinding`）

### 絶対にしないこと（守った）
- 新しい executor を足さない  
- ライブデータに対する実 mutation をしない  
- 「Clean 14GB」のような偽候補を出さない  
- UI 独自の Safety 判定エンジンを作らない

## 6. 製品が言えること（差別化）

この製品は両方言える。

- **「ここは安全に消せる」**（DerivedData / Ollama / HF の型）  
- **「ここは残すべき」**（Cursor / Voice Memos / Chrome サイト状態 / Claude 稼働ランタイム）

普通のクリーナーは前者しか言わない。  
AI Storage Manager の芯は後者を正しく言えること。

## 7. 残っている制限（正直）

1. Chrome / Claude / Voice Memos は **actionable=0**（研究完了だが掃除対象ではない）  
2. P4.0 スクショは **fixture-labelled**（ライブ ImageRenderer 置換は次）  
3. Interactive UI の ms 計測はレポート上 bounded／未ライブ  
4. vendor-specific UNKNOWN は残る（認可には使わない）
