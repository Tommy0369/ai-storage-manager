# AI Storage Manager P5.3 多言語対応

**日付:** 2026-09-08  
**判定:** DONE（Foundation）  
**次:** `P5.4_LOCALIZATION_RELEASE_QA`

## 結論

9言語の Localization Foundation を入れた。  
Safety の意味は変えていない。文言だけが変わる。

## 対応言語

1. English (`en`)  
2. 日本語 (`ja`)  
3. 简体中文 (`zh-Hans`)  
4. 繁體中文 (`zh-Hant`)  
5. 한국어 (`ko`)  
6. Español (`es`)  
7. Français (`fr`)  
8. Deutsch (`de`)  
9. Português (Brasil) (`pt-BR`)

デフォルトは **SYSTEM**（macOS に従う）。

## Localization architecture

- 意味キー → `L10n.t` → 単一カタログ  
- `LocalizationCatalog.json` + `Localizable.xcstrings`  
- `AppLanguage` / `LanguageStore`（Settings）  
- `LocaleFormatting`（byte / number / date）  
- View 内の language switch は禁止（使っていない）

## Safetyとの分離

- Locale は Presentation のみ  
- `verifiedRecoveredBytes` / executor / research freeze は不変  
- 翻訳文字列から Safety を判定しない  

## 主要UI

ナビ / スキャン状態 / Plan / History / Settings / 権限 / 主要 decision・action 文言をカタログ化。

## Safety Copy

`localization/safety-copy-glossary.md` を追加。  
KEEP / PROTECTED / VERIFY_MORE / Trash / Verified recovery の意味を固定。

## 数値・容量・日時

`LocaleFormatting` 経由。整数バイトの真実は変えない。

## Language setting

Settings → Language（国旗なし、言語名）。  
不正値は SYSTEM にフォールバック。

## UI崩れQA

- ドイツ語の長い Move to Trash をテスト  
- CJK / zh-Hans≠zh-Hant をテスト  
- 優先スクショの全量ビジュアルは **P5.4** に残す（正直に）
