# AI Storage Manager — 商店詮資料草稿（zh-Hant）

**產品名：** AI Storage Manager（官方名不翻譯）  
**通道：** macOS 直接發行用準備稿（勿自動提交）

## 副標題
看清 Mac 空間去向。安全決策。驗證結果。

## 簡短描述
AI Storage Manager 對照 Mac 上佔用空間的內容，說明它是什麼，並且只透過 Fresh Preflight → 核准 → Permit → Executor → PostVerify 執行動作。受保護的資料也是成功——不是失敗。

## 詳細描述
建置產物、AI 模型、App 狀態與備份會佔滿 Mac。僅憑大小無法判斷是否可安全處理。

本 App 協助您：

1. **看見** — 依意義劃分的儲存地圖，而不只是資料夾  
2. **理解** — 它是什麼、為何很大、依據為何  
3. **決定** — 保留 / 受保護 / 需要核實 / 就緒 — 基於證據  
4. **行動** — 僅在 Fresh Preflight 與您明確核准之後  
5. **驗證** — 操作後確認的本機回收量，與「可用空間估算」分開  

驗證回收在操作之後計量。移到垃圾桶不會立刻騰出空間，需在本 App 外清空垃圾桶。廠商原生清理（Ollama、Hugging Face）在符合條件時移除精確的本機目標。

## 要點
- 結構 / 意義 / 決策 三種透鏡的儲存地圖  
- 基於證據的 Safety 決策  
- 成功操作後的驗證回收總量  
- 保護進行中的工作（Cursor、語音備忘錄、Chrome 網站狀態、Claude 執行階段）  
- 九種語言離線在地化  

## 安全 / 隱私
- 不做整機自動清理  
- 不宣稱「刪除總是安全」  
- 無證據不宣稱雲端備份或保證可復原  
- 完整磁碟存取可提升可見性；受限存取仍可安全執行  

## 平台事實
- macOS 13.0+  
- 目前發行產物為 Apple 晶片（arm64）  

## 不要宣稱
- 自動垃圾清理 / 一鍵清理  
- 清理所有 App  
- 無證據的「釋放 X GB」  
- 未經證明的 Intel + Apple 晶片通用支援  
- 雲端備份服務
