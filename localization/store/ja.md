# AI Storage Manager — ストア用メタデータ下書き（ja）

**製品名:** AI Storage Manager（公式名は翻訳しない）  
**チャネル:** 直接配布用の準備原稿（自動提出しない）

## サブタイトル
Macの容量の行き先を見て、安全に決め、結果を確かめる。

## 短い説明
AI Storage Managerは、Macの容量の使い道を地図化し、何かを説明し、Fresh Preflight → 承認 → Permit → Executor → PostVerify のときだけ操作します。守る判断も製品の成功です。

## 長い説明
ビルド出力、AIモデル、アプリの状態、バックアップがMacを埋めます。大きさだけでは、触ってよいか分かりません。

このアプリは次を助けます。

1. **見る** — フォルダだけでなく、意味ごとのストレージ地図  
2. **理解する** — 何か、なぜ大きいか、根拠は何か  
3. **決める** — 残す / 保護 / 要確認 / 準備完了 — 推測ではなく根拠  
4. **動く** — Fresh Preflight と明示的な承認のあとだけ  
5. **確かめる** — 操作後に確認されたローカル回復量（空き容量の見積りとは別）  

検証済み回復は操作のあとに測ります。ゴミ箱へ移してもすぐ空きません。ゴミ箱を空にする操作はこのアプリの外です。ベンダー固有クリーンアップ（Ollama、Hugging Face）は、条件が合うとき正確なローカル対象を削除します。

## 要点
- 構造 / 意味 / 判断 のレンズ付きストレージマップ  
- 根拠に基づく Safety 判断  
- 成功した操作後の検証済み回復合計  
- 進行中の作業を守る（Cursor、ボイスメモ、Chromeのサイト状態、Claudeランタイム）  
- 9言語のオフラインローカライズ  

## 安全 / プライバシー
- Mac全体の自動クリーンアップはしない  
- 「いつも削除して安全」とは言わない  
- 根拠なしのクラウドバックアップや保証された回復は主張しない  
- フルディスクアクセスは見え方を広げる。制限付きでも安全に動く  

## プラットフォーム
- macOS 13.0+  
- 現行配布物は Apple silicon（arm64）
