# AI Storage Manager — 商店元数据草稿（zh-Hans）

**产品名：** AI Storage Manager（官方名不翻译）  
**渠道：** macOS 直接分发用准备稿（勿自动提交）

## 副标题
看清 Mac 空间去向。安全决策。验证结果。

## 简短描述
AI Storage Manager 映射 Mac 上占用空间的内容，解释它是什么，并且只通过 Fresh Preflight → 批准 → Permit → Executor → PostVerify 执行操作。受保护的数据也是成功——不是失败。

## 详细描述
构建产物、AI 模型、应用状态与备份会占满 Mac。仅凭大小无法判断是否可安全处理。

本应用帮助您：

1. **看见** — 按含义划分的存储地图，而不仅是文件夹  
2. **理解** — 它是什么、为何很大、依据是什么  
3. **决定** — 保留 / 受保护 / 需要核实 / 就绪 — 基于证据  
4. **行动** — 仅在 Fresh Preflight 与您明确批准之后  
5. **验证** — 操作后确认的本地回收量，与“可用空间估算”分开  

验证回收在操作之后计量。移到废纸篓不会立刻腾出空间，需在本应用外清空废纸篓。厂商原生清理（Ollama、Hugging Face）在符合条件时移除精确的本地目标。

## 要点
- 结构 / 含义 / 决策 三种透镜的存储地图  
- 基于证据的 Safety 决策  
- 成功操作后的验证回收总量  
- 保护进行中的工作（Cursor、语音备忘录、Chrome 站点状态、Claude 运行时）  
- 九种语言离线本地化  

## 安全 / 隐私
- 不做整机自动清理  
- 不宣称“删除总是安全”  
- 无证据不宣称云备份或保证可恢复  
- 完全磁盘访问可提升可见性；受限访问仍可安全运行  

## 平台事实
- macOS 13.0+  
- 当前发行产物为 Apple 芯片（arm64）  

## 不要宣称
- 自动垃圾清理 / 一键清理  
- 清理所有应用  
- 无证据的“释放 X GB”  
- 未经证明的 Intel + Apple 芯片通用支持  
- 云备份服务
