# AI Storage Manager — 스토어 메타데이터 초안 (ko)

**제품:** AI Storage Manager  
**채널:** macOS 직접 배포용 준비 원고（자동 제출하지 않음）

## 부제
Mac 저장공간이 어디로 갔는지 보고, 안전하게 결정하고, 결과를 확인하세요.

## 짧은 설명
AI Storage Manager는 Mac에서 공간을 쓰는 항목을 지도로 보여 주고, 무엇인지 설명하며, Fresh Preflight → 승인 → Permit → Executor → PostVerify 경로로만 동작합니다. 보호된 데이터도 성공입니다 — 실패가 아닙니다.

## 긴 설명
빌드 산출물, AI 모델, 앱 상태, 백업이 Mac을 채웁니다. 크기만으로는 안전한지 알 수 없습니다.

이 앱은 다음을 돕습니다.

1. **보기** — 폴더만이 아니라 의미 기준의 저장공간 맵  
2. **이해하기** — 무엇인지, 왜 큰지, 어떤 근거인지  
3. **결정** — 유지 / 보호됨 / 확인 필요 / 준비됨 — 추측이 아닌 근거  
4. **행동** — Fresh Preflight와 명시적 승인 후에만  
5. **확인** — 동작 후 확정된 로컬 회수량（여유 공간 추정과 분리）  

검증된 회수는 동작 이후에 측정됩니다. 휴지통으로 이동해도 바로 공간이 비지 않으며, 휴지통 비우기는 이 앱 밖에서 합니다. 벤더 네이티브 정리（Ollama, Hugging Face）는 조건이 맞을 때 정확한 로컬 대상을 제거합니다.

## 핵심 이점
- 구조 / 의미 / 결정 렌즈의 저장공간 맵  
- 근거 기반 Safety 결정  
- 성공한 동작 후 검증된 회수 합계  
- 진행 중 작업 보호（Cursor, 음성 메모, Chrome 사이트 상태, Claude 런타임）  
- 9개 언어 오프라인 로컬라이제이션  

## 안전 / 개인정보
- Mac 전체 자동 정리 없음  
- “항상 삭제해도 안전” 주장 없음  
- 증거 없는 클라우드 백업·보장 복구 주장 없음  
- 전체 디스크 접근은 가시성을 높이고, 제한 접근에서도 안전하게 동작  

## 플랫폼
- macOS 13.0+  
- 현재 배포 산출물은 Apple silicon（arm64）  

## 주장하지 말 것
- 자동 정크 클리너 / 원클릭 정리  
- 모든 앱 정리  
- 증거 없는 “X GB 확보”  
- 증명되지 않은 Intel + Apple silicon 유니버설  
- 클라우드 백업 서비스
