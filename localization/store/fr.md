# AI Storage Manager — Métadonnées App Store (fr)

**Produit :** AI Storage Manager  
**Canal :** Distribution macOS directe (brouillon préparé — ne pas soumettre automatiquement)

## Sous-titre
Voyez où est passé le stockage du Mac. Décidez en sécurité. Vérifiez le résultat.

## Description courte
AI Storage Manager cartographie ce qui utilise l’espace sur votre Mac, explique ce que c’est et n’agit que via Fresh Preflight → Approbation → Permit → Executor → PostVerify. Les données protégées sont aussi une réussite — pas un échec.

## Description longue
Sorties de build, modèles d’IA, états d’apps et sauvegardes remplissent le Mac. La taille seule ne dit pas ce qui est sûr.

Cette app vous aide à :

1. **Voir** — une carte par sens, pas seulement des dossiers  
2. **Comprendre** — ce que c’est, pourquoi c’est grand, quelles preuves  
3. **Décider** — Conserver, Protégé, Vérification requise ou Prêt — d’après des preuves  
4. **Agir** — seulement après Fresh Preflight et votre approbation explicite  
5. **Vérifier** — récupération locale confirmée après l’action, distincte des estimations d’espace libre  

La récupération vérifiée se mesure après l’action. Déplacer vers la Corbeille ne libère pas l’espace immédiatement ; vider la Corbeille se fait hors de cette app. Le nettoyage natif du fournisseur (Ollama, Hugging Face) retire des cibles locales exactes lorsqu’elles sont éligibles.

## Avantages clés
- Carte avec lentilles Structure / Sens / Décision  
- Décisions Safety fondées sur des preuves  
- Totaux de récupération vérifiée après actions réussies  
- Protège le travail actif (Cursor, Mémos vocaux, état des sites Chrome, runtime Claude)  
- Localisation hors ligne en neuf langues  

## Sécurité / confidentialité
- Pas de nettoyage automatique de tout le Mac  
- Pas de « toujours sûr de supprimer »  
- Pas d’affirmation de sauvegarde cloud ni de récupération garantie sans preuve  
- L’accès disque complet améliore la visibilité ; un accès limité reste sûr  

## Plateforme
- macOS 13.0+  
- Apple silicon (arm64) pour l’artefact actuel  

## Ne pas affirmer
- Nettoyeur automatique / nettoyage junk en un clic  
- Nettoie toutes les apps  
- « Libérez X Go » sans preuve  
- Support universel Intel + Apple silicon sans preuve  
- Service de sauvegarde cloud
